# Part 6a — Publish the agent in your organization

This step is tenant-specific and was not executed during the handoff build.

## Draft flow

1. Finish the Part 5 sideload test with a small developer group.
2. Validate app-manifest metadata, icons, privacy URL, and terms URL.
3. Package the Microsoft 365 app.
4. Submit it through the organization's approved app-upload process.
5. Have an administrator review and publish it through Integrated Apps /
   agent management.
6. Scope availability to a pilot group before broad rollout.
7. Confirm discoverability in Microsoft 365 Copilot and document rollback.

Reference:

- [Agents are apps for Microsoft 365](https://learn.microsoft.com/microsoft-365/copilot/extensibility/agents-are-apps)

Run Part 6b's evaluation baseline before widening availability.
