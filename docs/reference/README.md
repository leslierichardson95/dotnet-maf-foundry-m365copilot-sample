## Important implementation finding

The M365 outline predates the hands-on build and describes Part 5 as a
declarative agent calling the Hosted Agent through an action. Current
Microsoft 365 guidance classifies a solution that brings MAF orchestration and
a Foundry model as a **custom engine agent**.

Treat `docs\part-5-register-with-m365copilot.md` and
`HICCUPS-AND-DOC-OPPORTUNITIES.md` as the updated recommendation. The original
outline is intentionally preserved so the receiving team can see why the
documentation needs revision.
